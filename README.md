# مَقام | MAQAM — موقع قهوة عربية فاخر

موقع تجارة إلكترونية ثابت (Static) باللغة العربية (RTL) لعلامة القهوة **مَقام | MAQAM**، مبني بـ **HTML5 / CSS3 / JavaScript (Vanilla)** مع سلة مشتريات محلية (localStorage) وإتمام الطلب عبر واتساب.

## المزايا الرئيسية

- واجهة عربية كاملة باتجاه RTL وتجربة موبايل أولاً.
- هوية بصرية عربية أصيلة: عناوين بخط **Amiri**، وتوقيع العلامة بخط **Aref Ruqaa**، ونصوص واجهة بخط **Tajawal**، مع لوحة ألوان قهوة/كريمي/ذهبي عتيق هادئة.
- صفحات: الرئيسية (`index.html`)، المنتجات (`products.html`)، تفاصيل المنتج (`product.html`).
- 8 منتجات مع صور فعلية من مجلد `products/` (بدون تكرار للصور بين المنتجات)، مع نسخ مربّعة مهيّأة للبطاقات للصور غير المربعة.
- أوزان متعددة لكل منتج: **ربع كيلو (250g)**، **نصف كيلو (500g)**، **كيلو (1000g)**، ما عدا **القهوة المقطرة** فتُباع بعبوة واحدة بسعر **850 ج.م**.
- تخصيص خاص بالقهوة التركية فقط: **درجة القهوة** (سادة فاتح / سادة وسط / سادة غامق) و**إضافة الهيل** (بالهيل / بدون هيل) — كلاهما مطلوب.
- سعر إضافة الهيل للقهوة التركية يُحتسب تلقائياً حسب الوزن: **+50 ج.م للربع**، **+100 ج.م للنصف**، **+200 ج.م للكيلو**، ويظهر في سعر الوحدة وإجمالي السلة ورسالة واتساب.
- سلة مشتريات منزلقة مع حفظ في `localStorage`، فصل العناصر حسب المنتج + الوزن + التخصيص، تعديل الكمية والحذف والإجماليات الحية.
- إتمام الطلب عبر واتساب بالرسالة الجاهزة إلى الرقم: **+20 122 030 0708** (`201220300708`).
- رسوم متحركة خفيفة (IntersectionObserver / CSS / rAF) مع احترام `prefers-reduced-motion`.
- حماية أساسية: ترميز روابط واتساب، عدم استخدام `innerHTML` لمحتوى المستخدم، تحقق من مدخلات النماذج، تنظيف بيانات السلة المقروءة من التخزين المحلي.

## الهوية البصرية

- **Amiri**: خط النسخ الأساسي للعناوين الكبيرة والاقتباسات، لإحساس عربي أصيل وواضح.
- **Aref Ruqaa**: خط التوقيع لكلمة «مَقام» في الشعار، الهيرو، وشاشات الانتقال فقط.
- **Tajawal**: نصوص الواجهة والوصف والأزرار والليبلات، لضمان قراءة مريحة.
- **Cormorant Garamond**: الكلمات والأرقام الإنجليزية الصغيرة، مع تتبّع أحرف واسع.
- لوحة الألوان: إسبريسو داكن `#21120d`، كريمي `#f2e8d8`، ورقي `#faf5ea`، رقّ `#f4ecdf`، كتان `#ede2d1`، وذهبي عتيق `#b9925c`. الخلفيات الفاتحة تستخدم تدرجات دافئة هادئة بدلاً من الأبيض النقي.

```
│  ├─ data.js            # بيانات المنتجات والأسعار والعلامة (المصدر المركزي)

└─ products/             # صور المنتجات الأصلية (PNG) — تبقى دون تعديل
```

## تشغيل محلياً

الموقع ثابت ولا يحتاج بناء (build). للتشغيل محلياً (مستحسن لتجنب قيود بعض المتصفحات على الملفات المحلية):

```bash
# باستخدام Python
python -m http.server 8080

# أو باستخدام Node (إن توفر npx)
npx serve .
```

ثم افتح: `http://localhost:8080`

## تعديل الأسعار والمنتجات

جميع بيانات المنتجات والأسعار مركزية في: **`js/data.js`**

- داخل كل منتج، عدّل كائن `prices` (القيم بالجنيه المصري `EGP`):

```js
prices: {
  "250": 500,   // ربع كيلو — سعر قابل للتعديل
  "500": 1000,  // نصف كيلو — سعر قابل للتعديل
  "1000": 2000  // كيلو — سعر قابل للتعديل
}
```

- لإضافة قيمة الهيل حسب الوزن، استخدم `surcharges` داخل منتج القهوة التركية:

```js
surcharges: {
  cardamom: {
    with: { "250": 50, "500": 100, "1000": 200 }
  }
}
```

- المنتجات ذات العبوة الواحدة مثل **القهوة المقطرة** تعرّف قائمة أوزان خاصة بها وتُسعّر بمفتاح `package`:

```js
weights: [{ key: 'package', label: 'العبوة', grams: null, short: 'عبوة واحدة' }],
prices: { package: 850 }
```

- غيّر رقم واتساب من `BRAND.whatsapp` و`BRAND.whatsappDisplay` في نفس الملف.
- نص العملة والعملة: `BRAND.currency` (`ج.م`) و`BRAND.currencyCode`.
- **تنبيه:** الأسعار الحالية قيم افتراضية قابلة للتعديل؛ يتم تأكيد السعر النهائي مع العميل عبر واتساب.

## صور المنتجات

- الصور الأصلية موجودة في `products/` وتبقى دون تعديل، وتُستخدم مباشرة للصور المربعة (مع `object-fit: contain` للحفاظ على الأبعاد).
- للصور الخمس غير المربعة (مستكة، عربية ملكية، تورينو، نيلا، مقطرة) نُسخ مربّعة 1000×1000 في `assets/img/products/` مع الحفاظ على كامل العبوة والنص، لتظهر البطاقات بنفس اتساق باقي المنتجات.
- تم تضمين جميع الصور المتوفرة: تركي، فرنسية، فرنسية بندق، فرنسية مستكة، عربية ملكية، تورينو، كوفي نيلا، **قهوة مقطرة**.

## فيديو الواجهة الرئيسية

- فيديو الهيرو موجود في `assets/video/maqam-hero.mp4` بصيغة H.264/MP4 وبدون مسار صوتي.
- صورة الغلاف/البديل موجودة في `assets/img/hero-video-poster.jpg`، وتظهر فوراً قبل تشغيل الفيديو أو عند تعطيله.
- الفيديو يعمل تلقائياً بصوت مكتوم، ويتوقف ويظهر مكانه صورة الهيرو عند تفعيل «تقليل الحركة» أو «توفير البيانات» في المتصفح.
- لاستبداله: ضع ملف MP4/H.264 جديداً بنفس الاسم بدون صوت، وحدّث صورة الغلاف بنفس الاسم.

## الأمان والملاحظات

- `_headers` ملف ترويسات أمان **اختياري** لمنصات تدعمه (مثل Netlify/Cloudflare Pages). عند الاستضافة على خادم آخر، اضبط ترويسات مكافئة من إعدادات الخادم.
- الموقع ثابت (Front-end فقط): لا يمكن ضمان أمان الخادم من جانب الواجهة؛ لا يتم تخزين أسرار أو مفاتيح.
- لا توجد بوابة دفع؛ تأكيد الطلب والدفع والتوصيل يتم عبر واتساب.
- لا يتم جمع بيانات شخصية بخلاف ما يكتبه المستخدم في رسالة واتساب أو ما يُحفظ محلياً في السلة على جهازه.

## الترخيص

الكود والهوية النصية خاصة بعلامة **مَقام | MAQAM** ما لم يُذكر خلاف ذلك. صور المنتجات ومواد العلامة ملك لأصحابها. الصور التحريرية الخارجية مرخصة كما هو موضح أعلاه.
